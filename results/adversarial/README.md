# Adversarial UART validation subset

This folder contains the currently published small validation subset used to compare
the original and adversarially trained TinyConv on PC and Arduino.

Conditions include:
- clean;
- additive-noise conditions;
- FGSM ε=0.5;
- PGD ε=0.5.

The complete adversarial-generation / training workspace is not yet part of this public snapshot.
